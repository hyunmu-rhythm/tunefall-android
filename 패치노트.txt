[ v0.3.0 ] 2026-11-08
  - 게임 안 업데이트 추가
    · 다음 업데이트부터 게임을 켜면 새 버전을 자동으로 받아 바로 적용 (설치 확인 창 없음)
    · 앱을 새로 설치해야 하는 업데이트는 게임 안에서 받고 설치 화면까지 바로 연결
    · 업데이트 실패 시 오류 번호와 다시 시도 버튼 표시
  - 노래 선택 화면 개편 (PC v1.5.0 과 같음)
    · 제목 검색, 즐겨찾기, 정렬, 전체 / 즐겨찾기 / 최근 플레이 탭, 나만의 카테고리
    · 곡마다 최고 랭크와 최고 정확도 표시 (기존 곡은 한 번 플레이 후 표시)
    · 곡 목록과 버튼을 손가락으로 누르기 쉽게 크게 변경
  - 타격감 개선
    · 노트를 칠 때 짧은 진동 (설정에서 끄기 가능)
    · 롱노트를 누르는 동안 판정선에 불꽃 효과
    · 100콤보마다 콤보 강조 효과
    · 마지막 노트를 Miss 없이 치면 FULL COMBO / ALL PERFECT 표시
  - 버그 수정
    · 롱노트를 누르는 중 같은 레인을 다시 누르면 롱노트가 사라지던 문제 수정
    · 롱노트를 늦게 눌러 Miss 가 나면 노트가 갑자기 사라지던 문제 수정
  - 알아두기
    · 이번 v0.3.0 은 APK 직접 설치 필요 (다음 버전부터 게임 안에서 업데이트)
